# KAUSHALYA Cold Storage — Concept Website & Digital Demo

## What's included
- `index.html` — project website and interactive dashboard
- `style.css` — responsive styling
- `script.js` — simulated readings and demo scenarios

## Run locally in VS Code
1. Extract the ZIP file.
2. Open the `KAUSHALYA_Cold_Storage_Demo` folder in VS Code.
3. Open `index.html` in your browser, or install the VS Code extension **Live Server**.
4. If using Live Server: right-click `index.html` → **Open with Live Server**.
5. In the dashboard, choose a scenario and click **Run Scenario**.

## Important
This is a concept website and simulated digital prototype. It is NOT connected to physical hardware, real sensors, a battery, or live market data. Do not claim the physical machine has been built. The example readings are illustrative and should not be used for food-safety or engineering decisions.

## Publish with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. `kaushalya-cold-storage-demo`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish. Copy the exact website URL shown in Settings → Pages.
8. Open the URL in an incognito/private window to confirm it works before using it in the application.
